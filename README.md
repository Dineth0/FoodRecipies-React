#  Food & Recipe Sharing Platform (MERN + TypeScript)

A full-stack web application that allows users to explore foods, view related recipes, submit their own recipes for approval, and interact through reviews — built using the MERN stack with TypeScript following RAD principles.

This platform promotes community-driven cooking knowledge while ensuring quality control through an admin moderation system and analytics dashboard.

---

##  Live Demo

- **Frontend:** https://food-recipies-react.vercel.app/  
- **Backend:** https://incredible-carlie-dinethnakandala-d9594667.koyeb.app

##  Technologies Used

### Frontend
- React + TypeScript
- Redux Toolkit (State Management)
- Tailwind CSS
- Axios
- Vite

### Backend
- Node.js + Express.js (TypeScript)
- MongoDB Atlas
- Mongoose
- JWT Authentication
- bcryptjs
- Nodemailer (Email)
- Socket.io(Notifications)

### Deployment
- Frontend: Vercel  
- Backend: koyeb  
- Database: MongoDB Atlas  

---

##  Features

### User Features
- Browse food categories and view food details.
- View related recipes under each food item.
- Click recipe cards to view full recipe details.
- Submit reviews and ratings for recipes.
- Submit new recipes for approval.
- Receive email notification when recipe is approved or rejected.
- Download Recipes as PDF

### Admin Features
- Admin dashboard to manage food , recipes , pending recipes .
- Approve / reject user-submitted recipes.
- Analytics dashboard:
  - Recipe growth line chart.
  - Approved / Pending / Rejected recipe pie chart.
- Real-time notification when a user submits a recipe.

---

##  Advanced Features

- Analytics dashboard for recipe trends and moderation overview.
- Automated email notification system.
- Admin notification system for pending approvals.
- Download Recipes as PDF

---

##  System Architecture

- Client–Server Architecture
- RESTful API with Express + TypeScript
- Role-based authentication (User/Admin)
- Secure JWT token handling
- Modular folder structure
